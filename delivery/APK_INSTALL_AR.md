### تطبيق الأدمن
- Firebase حي: Auth + Firestore + AdminStatsService
- تم إعادة إنشاء مجلد `android/` كاملاً (كان ناقصاً) مع الحزمة الصحيحة `com.herafi.algeria.admin`
- minSdk = 23 (متطلب مكتبة Firebase Auth)
- **مهم:** بعد أول تسجيل دخول، يجب تشغيل `grant_admin.py` لمرة واحدة لمنحك دور الأدمن (انظر التفاصيل أدناه)

## خطوات التثبيت والتجربة (من هاتفك)

1. انقل ملفي APK إلى هاتفك (أرسلهما لنفسك عبر Telegram/WhatsApp/البريد)
2. ثبّتهما: قد يطلب الهاتف السماح بـ «تثبيت من مصادر غير معروفة» — وافق
3. التطبيقان مثبتان منفصلين على الهاتف (حزمتان مختلفتان)

### اختبار OTP
- في Firebase Console: Authentication → Sign-in method → Phone → أضف رقم اختبار (مثال: `+213555123456`) مع رمز مثل `123456`
- عند تسجيل الدخول بهذا الرقم في التطبيق، أدخل الرمز مباشرة (بدون رسالة SMS)

### منح دور الأدمن (مرة واحدة فقط)
1. سجّل الدخول في تطبيق الأدمن بأي رقم هاتف (نفس رقم الاختبار يعمل)
2. ستدخل التطبيق لكن لا ترى الإحصائيات الكاملة لأن دور الأدمن غير ممنوح بعد
3. نفّذ الأمر التالي على أي حاسوب/هاتف فيه Python:
```bash
python3 grant_admin.py GRANT <PHONE_NUMBER>
```
(استبدل `<PHONE_NUMBER>` برقمك كاملاً بالصيغة الدولية)
4. أعد تشغيل تطبيق الأدمن — سترى لوحة الإحصائيات كاملة

### نشر خادم الإشعارات (لاحقاً — اختياري)
- اتبع `RENDER_DEPLOY_GUIDE_AR.md` لنشر `herafi-fcm-relay` على Render (مجاني)
