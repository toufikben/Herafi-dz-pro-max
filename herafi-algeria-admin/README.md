# حرفي الجزائر - لوحة التحكم (Admin)

تطبيق أندرويد لإدارة منصة حرفي الجزائر.

## المميزات

- تسجيل دخول الأدمن
- لوحة إحصائيات (زبائن، حرفيين، طلبات، تقييم، تخصصات، ولايات)
- إدارة المستخدمين (الكل / حرفيون / زبائن) مع إجراءات: عرض، توثيق، حظر، حذف
- إدارة الطلبات مع تفاصيل
- إدارة التخصصات
- إعدادات المنصة

## التشغيل

```bash
cd herafi-algeria-admin
flutter pub get
flutter run
```

## البناء

```bash
flutter build apk --release
flutter build appbundle --release
```
